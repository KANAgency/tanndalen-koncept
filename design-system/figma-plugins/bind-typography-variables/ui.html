Typography sync

Uppdaterar font/size, font/tracking, font/style, font/family och font/leading (referens). Binder OG/* och TD/*: family, style, size, letterSpacing. Line height = 110/125/150 % på styles (ej variabel). Kopplar också varje Sample till rätt local text style. Skapar/uppdaterar även palett som color styles (OG/*, TD/* → variabler color/OG/*). Numerisk font/weight används inte i Figma. Skapar även layout-tokens: space/* (collection Spacing, modes OG/TD), plus delade radius/*, bp/*, z/* i Shared / Primitives.
